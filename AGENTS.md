# AGENTS.md

## Project Type
Static HTML/CSS website for Motel Mil Amores business. No build tools, no package.json, no tests.

## Development
- Open via static server (e.g., VS Code Live Server, `python -m http.server`)
- **Do NOT open directly as file://** - fonts use absolute path `/fuentes/` which requires a server
- No build commands required

## Available Skills
- `frontend-design` - use for UI enhancements, styling changes

## Files
- `index.html` - main entry
- `estilo.css` - all styles (no bundling)
- `funcion.js` - mobile menu, smooth scroll, animations
- `imagenes/` - images (webp, png)
- `fuentes/` - custom fonts (Poppins, DancingScript, Cinzel) - now uses Google Fonts (Cormorant Garamond, Montserrat)
